# Меню на месяц

PWA: меню на 4 недели, заготовки, тарелки по сухому весу, КБЖУ за день.

Публикация: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

Обновление: заменить `index.html` и поднять версию `CACHE` в `sw.js` (`menu-v1` → `menu-v2`), иначе телефоны будут показывать старую версию из кэша.
